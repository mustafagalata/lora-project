Veri akışı: question (str)
         → lang (TR|EN)
         → retrieved_context (str: "[1] ... [2] ...")
         → final_answer (str)

Bileşen sözleşmeleri (tool I/O):
  turkish_rag_search:  query (str) -> top_k chunks joined (str)
  wikipedia_search:    query (str) -> intro snippet(s) (str)
  reflect:             (question, sources, answer) -> "OK" | "REVISE: <reason>"
